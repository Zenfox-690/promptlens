Data and key handling

When you choose Optimize, the current prompt and PromptLens instructions are sent only to the selected provider. No prompt history or telemetry is stored by this extension.

Keys are stored in this browser profile with chrome.storage.local, not synchronized. Browser storage is not a secure vault; anyone able to inspect or compromise this profile may recover a key. Saving a key does not test or validate it.

Gemini's unpaid tier may use submitted prompts and responses to improve Google services and may involve human review. Do not send sensitive content. Check current terms, region, model access, and quotas before use.
